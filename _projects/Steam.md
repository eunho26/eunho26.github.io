This project aims to develop advanced hardware and control technologies for a teleoperated humanoid robot system capable of performing high-precision tasks in hazardous and unstructured environments. To ensure that operators can smoothly execute delicate operations from remote locations, the project focuses on the following areas:

First, development of avatar robot hardware and control technologies equipped with multi-modal sensors for remote environment perception. This includes building a high-precision teleoperation system for humanoid robots, designing dexterous robotic hands for fine manipulation, developing an operator station that minimizes physical fatigue, and implementing a control glove with high-resolution force feedback.

Second, development of human-level tactile sensing arrays and haptic feedback technologies. To dramatically enhance the grasping performance of robotic hands, an ultra-dense tactile sensing array will be created and integrated into key regions of the robotic hand. This enables the system to perceive and compensate for dynamic conditions such as tensor force, shear force, and slip. Complementary haptic feedback will be delivered to the operator through the control glove for realistic and immersive teleoperation.

Third, development of AR/VR interfaces that fuse multi-modal sensing information to support optimal decision-making by the operator. This involves creating advanced AR/VR display methods for efficient representation of sensor data, improving task efficiency through intuitive visualizations, and implementing 3D simulation systems to train and enhance operator skill in teleoperation.

Fourth, development of autonomous dual-arm manipulation technologies for handling deformable, fragile, or large-scale objects, enabling human–robot collaborative work. Key elements include mode-switching between teleoperation and autonomous control when task failures are predicted or detected, vision–tactile fusion reinforcement learning for deformable object manipulation, data augmentation for imitation learning to train fusion models, dual-arm motion planning for large-object handling, and explainable AI (XAI) frameworks for effective bidirectional human–robot collaboration.
